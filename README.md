# FINE3300-2026-A1
This repository includes my assignment 1 work on an exchange rate calculator.

## Project Overview

This project is a Python exchange-rate calculator that converts
between Canadian dollars (CAD) and US dollars (USD), using the
latest exchange rate in the supplied Bank of Canada data file.

## Program Structure

The ExchangeRates class reads the exchange-rate file.
Its convert method accepts an amount, a starting currency,
and a destination currency.
