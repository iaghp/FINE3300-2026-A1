# FINE3300-2026-A1
This repository includes my assignment work on the exchange rate calculator.

## Project Overview

This project is a Python exchange-rate calculator. It reads the most recent Bank of Canada's annual USD/CAD exchange rate data from the provided csv file and uses it to convert an amount from one currency to the other (CAD and USD). 

The user is prompted to provide the specific amount, current currency and the target currency. The result is then shown rounded to the nearest cent, with dollar signs and currency identifiers. 

## Files

| File | Description |
|------|-------------|
| `ExchangeRates.py` | Part 1: the calculator I wrote myself, without AI |
| `ExchangeRatesAI.py` | Part 2: the same calculator, generated by an AI model (vibe coding) |
| `BankOfCanadaExchangeRate.2026.csv` | Bank of Canada annual exchange rate data |

## How My Code Works

The `ExchangeRates` class is set up with the name of the data file. When it's created, it reads the file and stores the latest USD/CAD rate (the number of Canadian dollars per 1 US dollar).

The `convert(amount, from_currency, to_currency)` method:
- returns the amount unchanged if both currencies are the same
- multiplies by the rate to go from USD to CAD
- divides by the rate to go from CAD to USD

### Comparison of My Code and the LLM Code
Both programs gave the same answers: $100,000 USD became $139,780.00 CAD, and $100,000 CAD became $71,540.99 USD. They both use the latest rate of 1.3978, but read it differently. My code reads the file’s lines and takes the second-to-last value from the last row. Claude used `csv.DictReader` to find the rate by its column name, `FXAUSDCAD`. That approach is more efficient and would still work if the columns were rearranged. Mine depends on their current order. 

I also wrote separate conditions for USD to CAD and CAD to USD. Claude only checks whether the starting currency is USD and otherwise treats it as CAD. That works with the valid inputs assumed in the assignment, but I find my conditions easier and simpler. 

Claude also organized the program into a separate function, removed extra spaces from user input and let the user choose which exchange-rate file to open when running it. My program shows both exchange rates before asking for input, so the user can see the rates being used. I also included comments throughout, while Claude’s version has only one. 

The AI produced working code quickly, but building my version helped me understand what each part does, especially how to get the rate from the file and when to multiply or divide without importing the csv module.
